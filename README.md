# Cloud Curriculum – Gemini MVP

منصة مركزة لتحويل منهج رياضيات الصف الرابع الابتدائي السعودي إلى دروس تفاعلية باستخدام Gemini.

## ما الذي يتضمنه المشروع؟
- واجهة عربية RTL لرفع كتاب PDF وتوليد الدروس.
- استخراج النص الرقمي من PDF.
- OCR عربي/إنجليزي للصفحات المصورة عبر Tesseract.
- حفظ أرقام الصفحات والمصدر.
- توليد درس بصيغة JSON باستخدام Gemini REST API.
- منع اختيار درس عشوائي عند غياب عنوان واضح؛ يمكن تحديد نطاق صفحات صريح.
- حالة مراجعة للمحتوى قبل نشره للطفل.
- Docker Compose لتشغيل محلي.

## الإعداد
1. انسخ `.env.example` إلى `.env`.
2. ضع مفتاح Google AI Studio في `GEMINI_API_KEY` محليًا. لا تضع المفتاح في Git أو الواجهة.
3. شغّل:

```bash
docker compose up --build
```

4. افتح `http://localhost:8000`.

## توليد درس من صفحات محددة
بعد رفع الكتاب واكتمال التحليل، أرسل إلى `POST /api/lessons/generate`:

```json
{
  "document_id": "BOOK_ID",
  "lesson_title": "القيمة المنزلية ضمن مئات الألوف",
  "page_start": 14,
  "page_end": 16
}
```

أرقام الصفحات هي أرقام صفحات ملف PDF، وليست بالضرورة أرقام الطباعة داخل الكتاب.

## اختبارات
```bash
pip install -r requirements.txt
pytest -q
```

## ملاحظات مهمة
- معالجة كتاب كامل مصور قد تستغرق وقتًا؛ OCR يتم صفحة بصفحة.
- OCR العربي قد يخطئ في الأرقام والرموز الرياضية، لذا يجب مراجعة الدرس الناتج مع صفحات المصدر قبل اعتماده.
- التكامل الحقيقي مع Gemini يحتاج مفتاحًا صالحًا واتصال إنترنت. لا يحتوي المشروع على مفتاح API.
- لا يتم النشر على استضافة مدفوعة تلقائيًا.
